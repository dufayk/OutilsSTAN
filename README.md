# Outils STANISLAS

Page d'accueil regroupant les outils de suivi et d'organisation du lycée.

## Mise en ligne sur GitHub Pages

1. Sur github.com : **New repository** → nom `stanislas-outils` → **Public** → *Create repository*.
2. **Add file → Upload files** → glisser `index.html` (et ce README) → *Commit changes*.
3. **Settings → Pages** → *Source* : `Deploy from a branch` → branche `main`, dossier `/ (root)` → *Save*.
4. Après 1 à 2 minutes, la page est disponible sur :
   `https://<votre-identifiant>.github.io/stanislas-outils/`

## Ajouter une vignette

Dans `index.html`, copier un bloc `<a class="card" …>…</a>` dans la rubrique voulue, puis changer :
- `href` : le lien
- la classe de couleur de l'icône : `orange`, `teal`, `blue`, `pink`, `violet`, `green`, `indigo`, `red`
- le titre `<h3>` et le sous-titre `<p>`

> ⚠️ Une page GitHub Pages publique est visible par tous. Les liens SharePoint/OneDrive restent protégés par leurs propres droits d'accès.
